# Portafolio

Página web sencilla con mis proyectos. Se publica gratis con **GitHub Pages**.

## Cómo agregar un proyecto
Abre `projects.js`, copia un bloque `{ ... }`, pégalo al final de la lista y cambia el título, la descripción,
las tecnologías y el enlace del repositorio. Guarda y sube el cambio.

## Cómo publicarlo
1. Crea en GitHub un repositorio llamado `Portafolio` (público).
2. Sube estos archivos (`index.html`, `projects.js`, `README.md`).
3. En el repositorio: *Settings → Pages → Deploy from a branch → main / (root)*.
4. En un par de minutos estará en https://fjordan2212.github.io
